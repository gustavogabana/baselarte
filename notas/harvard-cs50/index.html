O que é o CS50What CS50 is

O CS50 é a disciplina de introdução à ciência da computação da Universidade de Harvard, dada pelo professor David J. Malan. A versão aberta para o mundo todo se chama CS50x: as aulas em vídeo, os exercícios e a correção automática são gratuitos. O site oficial a descreve como uma introdução ao uso de computação para resolver problemas, com e sem código, valorizando correção, design e estilo. Dois terços dos alunos nunca tinham feito uma disciplina de computação antes.CS50 is Harvard University’s introductory computer science course, taught by professor David J. Malan. The version open to the whole world is called CS50x: the video lectures, the exercises and the automatic grading are free. The official site describes it as an introduction to using computation to solve problems, with and without code, valuing correctness, design and style. Two thirds of students had never taken a computing course before.

Ele não ensina “uma linguagem”. Ele usa várias (Scratch, C, Python, SQL, HTML, CSS, JavaScript) como ferramenta para ensinar ideias que valem em qualquer lugar: abstração, algoritmos, estruturas de dados, memória, segurança e engenharia de software.It does not teach “a language”. It uses several (Scratch, C, Python, SQL, HTML, CSS, JavaScript) as tools to teach ideas that hold everywhere: abstraction, algorithms, data structures, memory, security and software engineering.

Curso gratuito, certificado opcional. Estudar e entregar os exercícios para correção não custa nada. O que pode ter custo é o certificado verificado da edX; existe também um certificado gratuito emitido pelo próprio CS50 (detalhes na seção “Como cursar”).Free course, optional certificate. Studying and submitting the exercises for grading costs nothing. What may cost money is the edX verified certificate; there is also a free certificate issued by CS50 itself (details in the “How to take it” section).

Um gostinho: “olá, mundo” em C e em PythonA taste: “hello, world” in C and in Python

O curso começa a programar de verdade pelo C. A mesma ideia nas duas linguagens mostra o que o Python faz por você. O exemplo de C é o clássico da semana 1 (usa a biblioteca cs50.h do curso, que já vem no ambiente dele). Não o executei aqui.The course starts real programming with C. The same idea in both languages shows what Python does for you. The C example is the classic from week 1 (it uses the course’s cs50.h library, already present in its environment). Como é: o ritmo de cada semanaWhat it is like: each week’s rhythm

  • Aulas. Vídeos longos e bem produzidos, com demonstrações ao vivo. As aulas foram dubladas para português e espanhol (via lingopal.ai), e existe uma versão do site em português em cs50.ly/pt.Lectures. Long, well-produced videos with live demonstrations. The lectures were dubbed into Portuguese and Spanish (via lingopal.ai), and there is a Portuguese version of the site at cs50.ly/pt.
  • Problem sets. É onde o aprendizado acontece. São programas de verdade, corrigidos por check50 (correção) e style50 (estilo). A nota semanal é 75% correção e 25% estilo. Não há prova; o requisito final é o projeto.Problem sets. This is where learning happens. They are real programs, graded by check50 (correctness) and style50 (style). The weekly score is 75% correctness and 25% style. There is no exam; the final requirement is the project.
  • Ambiente. O curso recomenda o Visual Studio Code do CS50 (cs50.dev), que roda no navegador com tudo já instalado, então você não precisa configurar compilador nenhum para começar.Environment. The course recommends CS50’s Visual Studio Code (cs50.dev), which runs in the browser with everything preinstalled, so you do not need to set up a compiler to start.
  • Projeto final. Você constrói um software seu, em qualquer linguagem, que resolva um problema real. Pode ser em grupo de até três pessoas (com escopo proporcional). O próprio enunciado sugere criar “algo que sobreviva ao curso”.Final project. You build software of your own, in any language, that solves a real problem. It can be in a group of up to three (with proportional scope). The brief itself encourages you to create “something that outlives this course”.
  • Dificuldade. A curva é íngreme nas semanas 1 a 5 (C, memória, estruturas de dados). É normal travar. O curso foi desenhado para isso: recomenda-se estimar de 10 a 20 horas por semana só nos problem sets.Difficulty. The curve is steep in weeks 1 to 5 (C, memory, data structures). Getting stuck is normal. The course is designed for it: it suggests estimating 10 to 20 hours per week on problem sets alone.

Como cursar, passo a passoHow to take it, step by step

  1. Crie as contas. Uma conta no GitHub (o certificado gratuito é resgatado com o login do GitHub) e uma conta na edX (o CS50 diz que o registro na edX é necessário para os dois tipos de certificado).Create the accounts. A GitHub account (the free certificate is claimed with the GitHub login) and an edX account (CS50 says edX registration is required for both certificate types).
  2. Entre no site do curso (cs50.harvard.edu/x), comece pela semana 0 e assista à aula. Se preferir em português, use a versão em cs50.ly/pt.Open the course site (cs50.harvard.edu/x), start at week 0 and watch the lecture. For Portuguese, use the version at cs50.ly/pt.
  3. Abra o ambiente (cs50.dev) e faça o problem set da semana, seguindo o enunciado.Open the environment (cs50.dev) and do the week’s problem set, following the brief.
  4. Teste e entregue. Rode check50 com o identificador do problema (está no enunciado) até passar, depois submit50 com o mesmo identificador. Os envios aparecem no seu Gradebook na hora.Test and submit. Run check50 with the problem’s identifier (it is in the brief) until it passes, then submit50 with the same identifier. Submissions show up in your Gradebook right away.
  5. Repita até a semana 10 e entregue o projeto final.Repeat through week 10 and submit the final project.
  6. Resgate o certificado, se quiser (veja abaixo).Claim the certificate, if you want one (see below).

E a IA? O pato de borracha e as regrasWhat about AI? The rubber duck and the rules

O CS50 não ignora a IA; ele a incorporou com regras claras. Existe o CS50 Duck, uma adaptação do ChatGPT para alunos e professores, disponível em cs50.ai e dentro do VS Code do curso (cs50.dev). O nome vem do rubber duck debugging: explicar o problema em voz alta, para um patinho de borracha, costuma revelar o erro. O pato foi desenhado como tutor: ele guia, faz perguntas e explica conceitos, mas não entrega a resposta do problem set.CS50 does not ignore AI; it built it in, with clear rules. There is the CS50 Duck, an adaptation of ChatGPT for students and teachers, available at cs50.ai and inside the course’s VS Code (cs50.dev). The name comes from rubber duck debugging: explaining the problem aloud to a rubber duck often reveals the bug. The duck was designed as a tutor: it guides, asks questions and explains concepts, but does not hand over the answer to the problem set.

A página do CS50 sobre o assunto diz que usar IAs de terceiros que sugerem ou completam respostas ou código é desonestidade acadêmica, a menos que o curso permita; as ferramentas do próprio CS50 (o pato) são aceitas. O texto da política pode ser atualizado: leia a versão vigente no site antes de submeter qualquer trabalho.CS50’s page on the subject says that using third-party AIs that suggest or complete answers or code is academic dishonesty unless the course allows it; CS50’s own tools (the duck) are accepted. The policy text can be updated: read the current version on the site before submitting any work.

Há mais um motivo, prático, para respeitar a regra mesmo sem ninguém conferindo: se uma IA resolve o problem set, você aprende o que a IA faz, não o que o curso quer que você aprenda. A nota perfeita sem o entendimento é um certificado de nada.There is one more reason, a practical one, to respect the rule even when nobody checks: if an AI solves the problem set, you learn what the AI does, not what the course wants you to learn. A perfect score without the understanding is a certificate of nothing.

Faz sentido na era da IA?Does it make sense in the AI era?

Opinião, não verificada nas fontes: o que segue é a minha leitura, apoiada nos fatos acima (conteúdo do curso e política de IA), não uma pesquisa sobre emprego nem uma garantia de resultado.Opinion, not verified in the sources: what follows is my reading, based on the facts above (course content and AI policy), not job-market research nor a guarantee of results.

Se uma IA escreve código, para que aprender a escrever? A resposta curta: para saber se o que ela escreveu está certo. Um assistente de código gera algo plausível e, de vez em quando, errado de um jeito sutil (um índice fora do limite, uma consulta que explode em volume, uma falha de segurança). Quem não tem a base não enxerga o erro e entrega o código mesmo assim.If an AI writes code, why learn to write it? The short answer: to know whether what it wrote is right. A coding assistant produces something plausible and, now and then, wrong in a subtle way (an out-of-bounds index, a query that blows up at volume, a security flaw). Someone without the foundation does not see the error and ships the code anyway.

Um jeito de estudar com IA sem se enganarA way to study with AI without fooling yourself

  1. Tente resolver sozinho primeiro, por um tempo definido (por exemplo, 30 minutos).Try to solve it on your own first, for a set time (for example, 30 minutes).
  2. Se travar, explique o problema em voz alta ou por escrito (o “pato de borracha” funciona até sem IA).If stuck, explain the problem aloud or in writing (the “rubber duck” works even without AI).
  3. Ainda travado? Pergunte ao pato do curso: peça uma dica, não a solução.Still stuck? Ask the course’s duck: ask for a hint, not the solution.
  4. Quando funcionar, faça o teste de explicar: consegue dizer o que cada linha faz, e por que, sem olhar? Se não, ainda não aprendeu.When it works, do the explain test: can you say what each line does, and why, without looking? If not, you have not learned it yet.
  5. Fora do curso, depois da base, use qualquer IA para produzir código, mas revisando linha a linha. É aqui que o CS50 se paga.Outside the course, after the base, use any AI to produce code, but review it line by line. This is where CS50 pays off.
