1. Harness: o que roda em volta do modelo1. Harness: what runs around the model

No dicionário de IA para programar de Matt Pocock, harness é tudo em volta do modelo que o transforma em agente: ferramentas, system prompt, gerenciamento de contexto, permissões e hooks. O modelo é stateless: só vê o que está na janela de contexto a cada requisição. A continuidade vem do harness reenviando a conversa e de arquivos no ambiente.In Matt Pocock's dictionary of AI coding, a harness is everything around the model that turns it into an agent: tools, system prompt, context management, permissions and hooks. The model is stateless: it only sees what is in the context window on each request. Continuity comes from the harness resending the conversation and from files in the environment.

O loopThe loop

Todo harness, do Claude Code ao seu script de cem linhas, repete a mesma coisa. O ponto de design importante é que o modelo nunca executa nada: ele pede uma ferramenta, e o harness decide se executa.Every harness, from Claude Code to your hundred-line script, repeats the same thing. The key design point is that the model never executes anything: it asks for a tool, and the harness decides whether to run it.

enquanto passos < limite:
    resposta = modelo(mensagens, ferramentas)
    se resposta não pede ferramenta:
        devolve resposta                     # condição de parada
    para cada pedido em resposta:
        resultado = guardrails(executa(pedido))   # o harness executa, não o modelo
        mensagens += resultado               # o ambiente vira o próximo contexto

A Anthropic resume assim: um agente é tipicamente um LLM usando ferramentas em loop, com feedback do ambiente a cada passo, e parando por uma condição de término ou por um limite como número máximo de iterações.Anthropic puts it this way: an agent is typically an LLM using tools in a loop, with environment feedback at each step, stopping on a completion condition or a limit such as a maximum number of iterations.

Context engineeringContext engineering

Se o modelo só vê a janela, o trabalho central do harness é decidir o que entra nela. A Anthropic chama isso de context engineering: curar o conjunto ótimo de tokens a cada inferência, não só escrever o prompt. As técnicas que se repetem nas fontes:If the model only sees the window, the harness's central job is deciding what goes into it. Anthropic calls this context engineering: curating the optimal set of tokens at each inference, not just writing the prompt. The techniques that repeat across the sources:

  • Context rot. Quanto mais tokens, pior a recuperação de detalhes. Contexto é recurso finito. Pocock chama de smart zone e dumb zone e sugere que a segunda costuma começar por volta de 125 a 150 mil tokens, número que ele mesmo diz ser debatido.Context rot. The more tokens, the worse the recall of details. Context is a finite resource. Pocock calls it the smart zone and dumb zone and suggests the latter often starts around 125 to 150 thousand tokens, a number he says is debated.
  • Recuperação just-in-time. Em vez de carregar tudo, guarde referências leves (caminhos, queries, links) e busque quando precisar. É a ideia por trás de skills e de RAG como ferramenta.Just-in-time retrieval. Instead of loading everything, keep lightweight references (paths, queries, links) and fetch when needed. This is the idea behind skills and RAG as a tool.
  • Compactação. Perto do limite, resumir a conversa e continuar numa janela nova. Primeiro maximize a retenção do essencial, depois corte o supérfluo, como resultados antigos de ferramentas.Compaction. Near the limit, summarize the conversation and continue in a fresh window. First maximize recall of the essentials, then trim the superfluous, like old tool results.
  • Notas estruturadas. O agente escreve em um arquivo fora da janela (lista de tarefas, NOTES.md) e relê depois.Structured notes. The agent writes to a file outside the window (to-do list, NOTES.md) and reads it back later.
  • Subagentes. Um agente especializado trabalha numa janela limpa e devolve só um resumo condensado ao principal.Subagents. A specialized agent works in a clean window and returns only a condensed summary to the main one.

Harness engineering: a práticaHarness engineering: the practice

Mitchell Hashimoto (criador do Terraform e do Ghostty) deu o nome em um texto de 2026: “sempre que você descobre que o agente cometeu um erro, dedique tempo a construir uma solução para que ele nunca mais cometa esse erro”. Ele descreve duas formas: melhorar o prompt implícito (uma linha no AGENTS.md, cada linha nascida de um mau comportamento) e criar ferramentas programadas (scripts que tiram screenshot, rodam testes filtrados), avisando o agente no AGENTS.md. O objetivo declarado é também que o agente consiga verificar o que fez.Mitchell Hashimoto (creator of Terraform and Ghostty) named it in a 2026 post: “anytime you find an agent makes a mistake, you take the time to engineer a solution such that the agent never makes that mistake again”. He describes two forms: better implicit prompting (a line in AGENTS.md, each line born from a bad behavior) and programmed tools (scripts that take screenshots or run filtered tests), told to the agent in AGENTS.md. The stated goal is also for the agent to be able to verify what it did.

AGENTS.md: um mapa, não um manualAGENTS.md: a map, not a manual

O AGENTS.md é descrito como um “README para agentes”: o que não cabe no README humano, como comandos de teste e convenções. Tudo o que está nele é carregado em toda sessão e custa tokens em todo turno, e quanto mais instruções se acumulam, menos confiável é o cumprimento de cada uma (verbete do próprio Pocock). Por isso:AGENTS.md is described as a “README for agents”: what does not fit the human README, like test commands and conventions. Everything in it is loaded in every session and costs tokens on every turn, and as instructions pile up, each one is followed less reliably (Pocock's own entry). So:

  • Entra: o que o agente não consegue deduzir do código: comandos exatos, convenções não óbvias, restrições duras (“nunca edite o cliente gerado”). Curto e declarativo.In: what the agent cannot infer from the code: exact commands, non-obvious conventions, hard constraints (“never edit the generated client”). Short and declarative.
  • Fica de fora: visão geral da arquitetura que o código já mostra, guias de estilo longos (vão para uma skill ou para docs/), e regras que um linter pode impor.Out: an architecture overview the code already shows, long style guides (they go to a skill or docs/), and rules a linter can enforce.
  • Critério de entrada: se você corrigiu o agente duas vezes no mesmo ponto, é candidato (Pocock). É a versão de Hashimoto: cada linha vem de um mau comportamento observado.Entry criterion: if you corrected the agent twice on the same point, it is a candidate (Pocock). It is Hashimoto's version: each line comes from an observed bad behavior.

  1. Ingestão (offline): carregar os documentos, quebrar em chunks (de preferência por título e seção, não por um número cego de caracteres), enriquecer cada chunk e indexar (BM25, vetores ou os dois).Ingestion (offline): load the documents, split into chunks (preferably by heading and section, not by a blind character count), enrich each chunk and index it (BM25, vectors or both).

INPUT=$(cat)
FILE_PATH=$(echo "$INPUT" | jq -r '.tool_input.file_path // empty')

  if [[ "$FILE_PATH" == *"$pattern"* ]]; then
    echo "Blocked: $FILE_PATH matches protected pattern '$pattern'" >&2
    exit 2
  fi

import os
import re
import sys
from pathlib import Path

SECRET = re.compile(r"(sk-[A-Za-z0-9_-]{16,}|AKIA[0-9A-Z]{16}|ghp_[A-Za-z0-9]{20,})")


class Denied(Exception):
    pass


def redact(text: str) -> str:
    return SECRET.sub("[REDACTED]", text)


def untrusted(source: str, text: str, limit: int = 2000) -> str:
    """Fence data that came from outside, so the prompt says it is not an instruction."""
    return f'<untrusted source="{source}">\n{redact(text[:limit])}\n</untrusted>'


class Policy:
    def __init__(self, root, writable=("notes",), max_steps=8):
        self.root = Path(root).resolve()
        self.writable = [self.root / w for w in writable]
        self.max_steps = max_steps

    def resolve(self, rel: str, write: bool = False) -> Path:
        path = (self.root / rel).resolve()
        if not path.is_relative_to(self.root):
            raise Denied("path escapes the workspace")
        if write and not any(path.is_relative_to(w) for w in self.writable):
            raise Denied("writes are only allowed under notes/")
        return path

    def approve(self, tool: str, args: dict) -> None:
        if os.environ.get("APPROVE") == "yes":
            return
        if sys.stdin.isatty():
            answer = input(f"\n[approval] {tool} {args}\nallow? [y/N] ")
            if answer.strip().lower() == "y":
                return
        raise Denied("a human did not approve this action")

Três detalhes de design: resolve() usa Path.resolve() antes de comparar, o que derruba ../ e links simbólicos; a aprovação falha fechada (sem terminal e sem APPROVE=yes, nega); e untrusted() trunca antes de redigir, para o limite de tamanho também valer para o que o modelo vê.Three design details: resolve() uses Path.resolve() before comparing, which defeats ../ and symlinks; approval fails closed (with no terminal and no APPROVE=yes, it denies); and untrusted() truncates before redacting, so the size limit also applies to what the model sees.

import re
import sqlite3
from pathlib import Path

STOPWORDS = {"a", "an", "and", "are", "do", "does", "how", "in", "is", "long", "of", "the", "to", "what", "when", "which"}


class DocIndex:
    """Chunk Markdown by heading and rank with BM25 (SQLite FTS5)."""

    def __init__(self, docs_dir: Path):
        self.db = sqlite3.connect(":memory:")
        self.db.execute("CREATE VIRTUAL TABLE chunks USING fts5(path UNINDEXED, heading, body)")
        for file in sorted(docs_dir.rglob("*.md")):
            for heading, body in self._split(file.read_text()):
                self.db.execute(
                    "INSERT INTO chunks VALUES (?, ?, ?)",
                    (str(file.relative_to(docs_dir.parent)), heading, body),
                )

    @staticmethod
    def _split(text: str):
        heading, lines = "(top)", []
        for line in text.splitlines():
            if line.startswith("#"):
                if lines:
                    yield heading, "\n".join(lines).strip()
                heading, lines = line.lstrip("# ").strip(), []
            else:
                lines.append(line)
        if lines:
            yield heading, "\n".join(lines).strip()

    def search(self, query: str, k: int = 3):
        words = [w for w in re.findall(r"\w+", query.lower()) if w not in STOPWORDS]
        if not words:
            return []
        match = " OR ".join(f'"{w}"' for w in words)
        return self.db.execute(
            "SELECT path, heading, body FROM chunks WHERE chunks MATCH ? "
            "ORDER BY bm25(chunks) LIMIT ?",
            (match, k),
        ).fetchall()

import re
from pathlib import Path

NAME = re.compile(r"^[a-z0-9]+(-[a-z0-9]+)*$")


def _parse(path: Path):
    head, _, body = path.read_text().partition("\n---\n")
    meta = dict(
        line.split(":", 1) for line in head.removeprefix("---\n").splitlines() if ":" in line
    )
    return {k.strip(): v.strip() for k, v in meta.items()}, body.strip()


class Skills:
    def __init__(self, skills_dir: Path):
        self.items = {}
        for file in sorted(skills_dir.glob("*/SKILL.md")):
            meta, body = _parse(file)
            name, desc = meta.get("name", ""), meta.get("description", "")
            if not NAME.match(name) or len(name) > 64 or name != file.parent.name:
                raise ValueError(f"{file}: invalid skill name {name!r}")
            if not 0 < len(desc) <= 1024:
                raise ValueError(f"{file}: description must have 1 to 1024 characters")
            self.items[name] = (desc, body)

    def catalog(self) -> str:
        return "\n".join(f"- {n}: {d}" for n, (d, _) in self.items.items())

    def load(self, name: str) -> str:
        return self.items[name][1]

import json

from .guard import Denied, Policy, redact, untrusted
from .rag import DocIndex
from .skills import Skills


def spec(fn_name, description, **params):
    return {
        "type": "function",
        "function": {
            "name": fn_name,
            "description": description,
            "parameters": {
                "type": "object",
                "properties": {k: {"type": "string", "description": v} for k, v in params.items()},
                "required": list(params),
            },
        },
    }


class Tools:
    def __init__(self, policy: Policy, index: DocIndex, skills: Skills):
        self.policy, self.index, self.skills = policy, index, skills
        self.schemas = [
            spec("search_docs", "Search the project docs (BM25). Returns the best chunks with their file path.",
                 query="keywords, not a full sentence"),
            spec("read_file", "Read a file in the workspace by relative path, e.g. docs/setup.md.",
                 path="relative path"),
            spec("write_file", "Write a text file under notes/. A human must approve every call.",
                 path="relative path under notes/", content="file content"),
            spec("load_skill", "Load the full instructions of a skill from the catalog.",
                 skill="skill name"),
        ]

    def call(self, name: str, raw_args: str) -> str:
        try:
            args = json.loads(raw_args or "{}")
            return redact(getattr(self, f"_{name}")(**args))
        except Denied as why:
            return f"DENIED: {why}"
        except (AttributeError, TypeError, KeyError, json.JSONDecodeError) as err:
            return f"ERROR: bad call to {name}: {err!r}"
        except OSError as err:
            return f"ERROR: {err.strerror}"

    def _search_docs(self, query):
        hits = self.index.search(query)
        if not hits:
            return "no results"
        return "\n".join(untrusted(f"{p}#{h}", body) for p, h, body in hits)

    def _read_file(self, path):
        return untrusted(path, self.policy.resolve(path).read_text())

    def _write_file(self, path, content):
        target = self.policy.resolve(path, write=True)
        self.policy.approve("write_file", {"path": path, "bytes": len(content)})
        target.write_text(redact(content))
        return f"wrote {path}"

    def _load_skill(self, skill):
        return self.skills.load(skill)

import json
import time

from .guard import redact


def run(question, llm, tools, system, max_steps, trace):
    messages = [{"role": "system", "content": system}, {"role": "user", "content": question}]
    for step in range(max_steps):
        msg = llm.chat(messages, tools.schemas)
        messages.append(msg)
        calls = msg.get("tool_calls") or []
        if not calls:
            return redact(msg.get("content") or "")
        for call in calls:
            fn = call["function"]
            started = time.time()
            result = tools.call(fn["name"], fn["arguments"])
            trace({"step": step, "tool": fn["name"], "args": fn["arguments"],
                   "result": result[:200], "ms": round((time.time() - started) * 1000)})
            messages.append({"role": "tool", "tool_call_id": call["id"], "content": result})
    return f"stopped: step limit ({max_steps}) reached"

import json
import re
import urllib.request


class OpenAICompatible:
    """Any /v1/chat/completions server: Ollama, vLLM, LM Studio or a hosted API."""

    def __init__(self, base_url, model, api_key=""):
        self.url, self.model, self.key = base_url.rstrip("/") + "/chat/completions", model, api_key

    def chat(self, messages, tools):
        body = json.dumps({"model": self.model, "messages": messages, "tools": tools, "temperature": 0})
        req = urllib.request.Request(self.url, body.encode(), {
            "Content-Type": "application/json",
            **({"Authorization": f"Bearer {self.key}"} if self.key else {}),
        })
        with urllib.request.urlopen(req, timeout=180) as res:
            return json.load(res)["choices"][0]["message"]


class ScriptedModel:
    """A fake model for tests: searches, answers from the result, and obeys injected 'WRITE' lines.
    The obedient part is deliberate: the harness must hold even when the model is compromised."""

    def chat(self, messages, tools):
        last = messages[-1]
        if last["role"] == "user":
            return self._call("search_docs", {"query": last["content"]})
        injected = re.search(r"WRITE (\S+) :: (.+)", last["content"])
        if last["role"] == "tool" and injected and not last["content"].startswith("DENIED"):
            return self._call("write_file", {"path": injected[1], "content": injected[2]})
        found = [m["content"] for m in messages if m["role"] == "tool" and m["content"].startswith("<untrusted")]
        return {"role": "assistant", "content": "From the docs:\n" + (found[0][:400] if found else "nothing found")}

    @staticmethod
    def _call(name, args):
        return {"role": "assistant", "content": None, "tool_calls": [
            {"id": "call_1", "type": "function", "function": {"name": name, "arguments": json.dumps(args)}}]}
