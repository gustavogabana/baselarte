Notes

Things we learned, written down.

Short, practical references on the tools and platforms we build with. Pick a topic.

  • How Linux works Visual guide: users and root, permissions, file tree, commands, processes, networking, SSH, firewall, terminal and web tools, and clearing history, with diagrams and exam questions. →
  • Postgres for developers Relational databases 80/20: schemas, roles and passwords, access security, indexes, CTEs, UUIDs, full-text search, backups (3-2-1) and caching, with a Docker lab. →
  • React state: Context API and Zustand From the official docs: prop drilling, createContext and useContext, the reducer + context pattern, Zustand stores and selectors, per-request stores in Next.js, and when to use each. →
  • Anatomy of a full-stack platform Case study of a real front end and back end: API-first, layered caching, security, direct uploads, batched analytics and tests. →
  • AWS An interactive guide based on the official documentation: IAM, VPC, ECS, RDS, S3, Route 53 and more, with diagrams and simulators. →
  • Cloudflare: domain, R2 and SSL Buy and configure a domain, R2 with presigned URLs, CDN, SSL certificates, and HTTPS all the way to an AWS load balancer. →
  • Terraform 80/20 The 20% of Terraform that covers 80% of the work: workflow, HCL, state, modules, and a complete AWS walkthrough with remote state, VPC, EC2 and S3. →
  • GitHub to AWS with OIDC CI/CD with GitHub Actions: a push to develop or main deploys to AWS using OIDC, with no stored access keys. →
  • Security and networking lab Hands-on exercises on your own machines: sessions, stateful vs. stateless, nmap, SSH, WireGuard VPNs you host yourself, Wireshark, firewalls and basic recon tools, plus Docker networking explained. →
  • Red team 80/20 Offensive concepts and defences: the attack lifecycle, social engineering and phishing simulation, SQL injection and XSS, reverse shells, all in a safe Docker lab, each technique paired with its defence. →
  • Secure web apps: headers, auth and AI agents HTTPS and security headers (HSTS, CSP with nonces, building your own middleware, Next.js and Nginx), cookie attributes, stateful sessions vs. stateless JWT (access + refresh tokens), CSRF, SQL injection and XSS from the builder's side, and the new frontier: AI agent security, per OWASP. →
  • Grokking Algorithms Book notes: Big O notation, binary search, sorting, recursion, hash tables, graphs, Dijkstra, greedy algorithms, dynamic programming and k-NN, with everyday examples and code. →
  • Software Engineering at Google Book notes: time, scale and trade-offs, Hyrum’s Law, testing, code review and continuous delivery, explained with simple examples and diagrams. →
  • AI Engineering Book notes: tokens, sampling, prompting, RAG, agents, evaluation, LoRA finetuning, inference and architecture, with simple examples and diagrams. →
