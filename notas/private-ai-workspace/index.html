Daí a definição prática que a nota usa: uma IA “que não envia dados” é aquela em que você consegue listar, por função, para onde cada dado pode ir, e a rede impede o resto. A palavra importante é impede. Uma promessa de “sem telemetria” no README é uma afirmação sobre o código de hoje; um firewall é uma garantia independente do código. The key word is blocks. A “no telemetry” promise in the README is a statement about today's code; a firewall is a guarantee independent of the code. The two add up, but only the second holds when the code changes or is tricked by malicious text (see agents).

Nuvem também conta. Rodar numa VM sua em um provedor de nuvem mantém os dados fora de qualquer API de IA de terceiros, mas o provedor continua hospedando o disco. “Não envia dados” aqui significa nenhum serviço de IA de terceiros recebe seus dados, não “ninguém além de mim consegue tecnicamente ver”. Para dados regulados ou muito sensíveis, essa diferença importa e foge do escopo desta nota.The cloud counts too. Running on a VM of yours at a cloud provider keeps data away from any third-party AI API, but the provider still hosts the disk. “Does not send data” here means no third-party AI service receives your data, not “nobody but me can technically see it”. For regulated or highly sensitive data that difference matters and is outside this note's scope.
